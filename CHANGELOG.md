## 0.8.1 Initial 

🎉 Initial release of the public demo / freemium edition.

- 🔌 Unified Flutter/Dart VPN API for sing-box and Xray-core.
- 📱 Android and Apple Silicon macOS support.
- 🌐 VLESS and Shadowsocks support; Hysteria2 and TUIC via sing-box.
- ⚙️ Core setup commands and configurable core versions.
- 📄 Connections through share links or compatible JSON configurations.
- 🔐 Connection key storage with `VpnKeyStorageService`.
- 🧭 Custom routing presets, private-network routing, and sniffing options.
- 📋 Runtime logs for connection diagnostics.

🔒 Windows integration and additional protocols are available separately in the commercial edition.

🚧 iOS support is in priority development and is not available yet.
